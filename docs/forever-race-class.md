# WoW Forever: race × class × faction

Checked 2026-11-01 against the sources below. WoW Forever launches on 2026-11-04 (client 1.60.1);
recheck after launch, because the beta table could still change.

10 races (Skyborne counts as one race in two faction variants), 9 classes, no new classes.
Races from The Burning Crusade onward are not playable.

Totals: 56 race-variant × class pairs (23 Alliance without Skyborne, 23 Horde without Skyborne,
5 + 5 Skyborne). Some guides say 52, which counts Skyborne as one race with 6 classes.

Facts the quiz depends on:

- Six new pairs on Classic races: Human Hunter, Dwarf Shaman, Gnome Priest, Orc Mage, Troll Warlock,
  Undead Paladin. Night Elf and Tauren get nothing new.
- Every class is open to both factions: Paladin is no longer Alliance-only (Undead), Shaman is no
  longer Horde-only (Dwarf).
- Skyborne: Mage only for the Alliance variant, Shaman only for the Horde variant; Warrior, Hunter,
  Rogue and Druid for both. Skyborne druids have their own shapeshift forms.
- Skyborne needs a paid edition (Skyborne Heroic Pack or higher); the rest of the game needs only
  game time. This is why the quiz has a Skyborne toggle.
